1. 오늘 한 것
* 원형 / AABB / OBB Bounding Box 시각화
* 세 방식 충돌 ㅏㄴ정 차이 관찰

2. 관찰 내용 

* 원형 vs AABB
-모서리 충돌의 차이와 객체의 형태에 따라 적합도가 달라 시각과 판정의 불일치를 확인하였다
* AABB vs OBB
-중앙의 사각형이 회전할 때 AABB는 사각형 전체를 덮기 위해 크기가 커졌다 작아지기를 반복하여 45도 기울어졌을 때는 좀 거리가 있어도 hit가 발생하였다
반면 obb는 오브젝트와 정확한 각도로 회전하며 크기를 유지하였으며 시각적인 형태와 일치하는 지점에서만 hit판정이 나왔다
* AI와의 대화에서 배운 것
-sqrt를 생략해도 되는 것 같은 거리 계산 최적화를 AI와 소통하면서 배울 수 있었다
3. 내 게임에 적용한다면
-내가 게임을 만들때는 아마 정확한 판정을 요구하는 그런 장르의 게임을 만들 것 같기 때문에 obb를 적용하여 게임의 판정에서 오류가 나오지 않도록 할것 같다
